# Netly

> A modern Android video and audio downloader designed for a simple, fast, and convenient downloading experience.

## 📱 About Netly

Netly is an Android media downloader focused on providing a clean and easy-to-use experience for downloading video and audio content.

The app provides flexible format and quality options while keeping the interface simple and lightweight.

## ✨ Features

- 🎥 Video downloading
- 🎵 Audio downloading
- 📥 Multiple quality and format options
- 🔎 Media search
- ⚡ Fast and simple download workflow
- 📂 Downloaded media management
- 🌙 Modern light and dark theme support
- 🔄 In-app update checker
- 📱 Android-optimized interface
- 🎨 Clean neumorphic-inspired UI

## 🎬 Download Options

Netly provides different download options depending on the media available, including:

### Video
- Different video resolutions
- Available quality options
- Format selection

### Audio
- MP3
- M4A
- Different available audio qualities

The available formats and qualities are detected dynamically.

## 🔄 In-App Updates

Netly includes an in-app update checker connected to GitHub Releases.

When a newer production release is available:

1. Netly detects the new release.
2. The release information is retrieved from GitHub.
3. The user is shown an update dialog.
4. GitHub release notes are displayed automatically.
5. The latest APK can be downloaded directly.
6. Android's package installer is used to install the update.

The update checker does not require GitHub authentication credentials inside the application.
